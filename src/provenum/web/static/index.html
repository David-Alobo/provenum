provenum

Tie the numbers in your paper to the tables that produced them. Your manuscript stays on this machine; the only other connection is to the model server you choose.

1 Your paper

In Overleaf: Menu → Download → Source. Upload that zip here, or any zipped LaTeX project.

2 Your result tables

The CSV files your analysis wrote. Upload them as a zip, or use a folder that is already in the project.

3 How each table is read

provenum guessed which columns name a row and how each column is printed (percent, p-value, signed difference). Every guess has a comment; fix any that are wrong. Lines marked CHECK need a look.

4 Find where each number comes from

For every number typed by hand, provenum finds the table cells with the same value. A local model (through Ollama) then picks the cell the sentence means. Without a model, you pick.

5 Review

Nothing changes in your paper until you apply. A number is replaced only by a cell whose value, printed as the spec says, gives exactly what you wrote, so the PDF reads the same.

    6 Take it back to Overleaf

    Download project.zip Report numbers.toml

    In Overleaf: New Project → Upload Project with project.zip opens the linked version as a new project, so the original stays untouched. Keep numbers.toml with your analysis: after a rerun, provenum values regenerates numbers.tex and provenum diff lists the sentences whose claims changed.
